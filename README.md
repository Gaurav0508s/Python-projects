# Certificate Verification System

A simple Python-based certificate verification system that allows users to add, verify, search, revoke, and delete certificates.

## Features

* Add new certificates
* Verify certificates using Certificate ID
* View all certificates
* Search certificates by student name or course
* Revoke certificates
* Delete certificates
* Prevent duplicate Certificate IDs
* Store certificate data permanently using JSON
* Simple menu-based interface

## Technologies Used

* Python
* JSON
* File Handling
* Dictionaries
* Functions

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python certificate_verification.py
```

4. Select an option from the menu.
